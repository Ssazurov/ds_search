# ADR-0012: Определение агрегаторов — ссылка на первоисточник из текста статьи

Дата: 2026-09-18 (ред. после уточнения). Статус: Accepted.

## Проблема
wildcar.ru — агрегатор: в конце каждой статьи есть строка
`Источник: [домен](url)` со ссылкой на реального автора (пример:
sonoticiaboa.com.br). Атрибуция сейчас указывает на wildcar, а не на
реальный источник.

## Решение
1. `config/licenses.yaml`: поле `is_aggregator: bool` (default `false`).
   Для wildcar.ru — `true`.
2. В пайплайне (`add_news_by_url.py`/`collect_news.py`), после скачивания
   страницы агрегатора: если `is_aggregator: true` — распарсить в уже
   скачанном тексте статьи финальную ссылку-источник (паттерн
   `Источник: [текст](url)` / аналог на pt/en) регуляркой/просто поиском
   последней внешней ссылки перед футером.
   - Найден URL → используется как `source_url` для атрибуции
     (домен ссылки при этом **не** обязан быть в license-реестре —
     сам первоисточник не скачиваем, только берём ссылку и делаем summary
     по тексту, который уже скачан с wildcar).
   - Не найден → текущее поведение (атрибуция на wildcar, warning в лог).
3. **Первоисточник не краулим** — ни для проверки лицензии, ни для полного
   текста. Только summary по тексту агрегатора + ссылка на источник.
4. `ui/sources_tab.py`: бейдж "Агрегатор" при `is_aggregator: true`.

## Не делаем
- Не ищем первоисточник через поиск/LLM, если ссылки нет в тексте —
  просто используем агрегатор как источник (текущее поведение).
- Не строим отдельный сервис агрегаторов.
