# ADR-004: Продукт №1 — сайт (глоссарий, ссылки, статьи + RAG-чат)

Дата: 2026-09-08. Статус: принято. Эпик: #23.

## Контекст
Нужен публичный сайт для родителей детей с СД и специалистов: глоссарий,
ссылки на ресурсы, статьи, RAG-чат. Свой контент сайт не хранит — данные
и поиск через существующий GAR API (issue #23 body).

## Решение
- Репозиторий: `ds_site` (github.com/Ssazurov/ds_site), отдельный от
  `ds_search`/`ds_ingestion`/`gar-admin-ui`.
- Стек: Next.js + Tailwind — тот же паттерн, что в `gar-admin-ui`
  (SSR/SSG, React 19, Tailwind 4), но без общего кода/пакетов —
  независимый репозиторий, конфиги взяты как отправная точка, не
  как жёсткая зависимость.
- Страницы глоссария/статей — SSG/ISR (статика, SEO, скорость).
  RAG-чат-виджет — client-side компонент.
- Без встроенной админки: управление контентом (в т.ч. модерация
  новостей) — в `ds_search/ui/` (Streamlit, см. ADR-003).

## Альтернативы
- Общий монорепо/дизайн-система с `gar-admin-ui` — отклонено: разное
  назначение (публичный сайт vs админка) и планируется независимая
  эволюция оформления/стека каждого продукта.
- Astro — рассмотрен для более лёгкой SSG-сборки; отклонено в пользу
  консистентности со стеком `gar-admin-ui` (легче переносить наработки
  RAG-чат-виджета).
