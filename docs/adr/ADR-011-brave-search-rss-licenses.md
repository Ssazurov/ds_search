# ADR-011: Brave Search вместо/в дополнение к Tavily + закрытие license-гейта для RSS-доменов

Дата: 2026-09-17. Статус: принято.

## Контекст
Tavily keyless-режим (ADR из issue #162) сейчас отдаёт 403 — второй день
подряд, `collect_news.py` не работает вообще. Объём нужен скромный:
10-50 новостей/день, не тясячи. Отдельно: RSS-пайплайн (ADR-010,
`config/rss_sources.yaml`, 8 доменов) уже даёт кандидатов, но 5 из 8
доменов не имеют записи в `licenses.yaml` -> `_collect_one` их молча
блокирует license-гейтом (issue #3), т.е. RSS-канал фактически наполовину
не работает уже сейчас, независимо от Tavily.

## Решение
1. **SearchProviderChain**: добавить `BraveProvider` (Brave Search API,
   free tier 2000 запросов/мес — с запасом хватает на 10-50/день) как
   элемент цепочки. Порядок в chain: Brave первым (раз Tavily нестабилен),
   Tavily остаётся вторым звеном как фолбэк на случай возврата
   доступности — chain уже поддерживает несколько провайдеров, менять
   архитектуру не нужно.
2. **licenses.yaml**: доразобрать 5 доменов без записи из
   `rss_sources.yaml` (asi.org.ru, philanthropy.ru, takiedela.ru,
   nakedheart.online, rusfond.ru) — то же самое ручное ToS-review, что и
   для issue #164, но для RSS-доменов приоритет выше: без записи в
   licenses.yaml RSS-канал их не скачивает вообще, а не "не публикует".
3. issue #164 (доразбор ~13 доменов из пилота Tavily) остаётся отдельной
   задачей более низкого приоритета — это домены, найденные поиском, а не
   курируемый RSS-список.

## Альтернативы
- DuckDuckGo HTML-скрейпинг — отклонено: неофициальный, риск блокировки
  по UA/частоте, при 10-50/день выигрыш в цене не оправдывает
  нестабильность.
- SearXNG self-hosted — отклонено на этом шаге: требует отдельного
  контейнера в deploy/docker-compose, лишняя инфраструктура при
  скромном объёме; можно вернуться, если Brave free tier не хватит.
- Полностью убрать SearchProviderChain и остаться только на RSS —
  отклонено: RSS даёт кандидатов только с 8 курируемых доменов, поиск
  нужен для остального потока (issue #61 изначальная цель).

## Дополнение от 2026-09-17 (после реализации)
Обе предпосылки решения №1 не подтвердились на проверке:
- **Brave**: бесплатный тир (2000 запросов/мес) снят с продажи в конце
  2025 — теперь только prepaid с обязательной картой ($5 бесплатных
  кредитов/мес ≈ 1000 запросов). `BraveProvider` (issue #169) реализован
  и остаётся в codebase как опциональное звено, но не включается без
  явного решения платить/давать карту.
- **Tavily**: 403 оказался не проблемой keyless-режима, а тем, что
  `api.tavily.com` не отвечает из рабочей сети совсем (TLS-хендшейк
  проходит, HTTP-ответ не приходит — похоже на сетевую блокировку, не на
  API). С реальным `TAVILY_API_KEY` тот же результат.
- Проверены альтернативы с той же сети: `api.firecrawl.dev` отвечает
  быстро и штатно (200), бесплатный тир 1000 кредитов/мес без карты.
  Новое решение — `FirecrawlProvider` первым звеном в `SearchProviderChain`
  вместо Brave; Tavily/Brave остаются в коде как фолбэк-опции на случай
  смены сети/тарифов. См. issue (создан 2026-09-17) в ds_search.
