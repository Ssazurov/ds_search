# Требования: metadata category и lifecycle_stage

Статус: готово к реализации
Issue: #33
ADR: [ADR-0002](../adr/0002-rag-agent-capabilities.md)

## Цель
Каждый источник/чанк, передаваемый из ds_search в ingestion-контур, должен
нести контролируемые metadata `category` и `lifecycle_stage`. Эти поля нужны для
навигации по этапам жизненного пути семьи и последующей фильтрации retrieval.

## Требования

1. `category` передаётся как значение существующего контролируемого словаря.
2. `lifecycle_stage` передаётся отдельным значением, без подмены `category`.
3. Отсутствующие значения не заполняются догадкой и сохраняют согласованный
   nullable/пустой статус до ручной классификации.
4. Существующие metadata и обратная совместимость текущего discovery/download
   пайплайна сохраняются.
5. Реализация покрывается focused-тестами на формирование и передачу обоих
   полей, включая отсутствие значений.

## Не входит
Изменение retrieval/generation, UI диалога, структуры GAR API и массовая
переклассификация уже собранных документов.
