# UI: Вывод сообщений о результатах операций

С issue #366 введён единый механизм вывода сообщений через модуль `ui/notify.py`.

## Правила

1. **Всегда используйте `notify.report` / `notify.report_batch` / `notify.toast`** для вывода результатов операций.
2. **Прямые вызовы `st.success()`, `st.error()`, `st.warning()`, `st.info()` запрещены** в `ui/*.py` (кроме `notify.py`).
3. **Допустимые исключения** (явно перечислены в охранном тесте `tests/test_no_bare_messages.py`):
   - Пустые состояния (нет данных для отображения)
   - Inline-подсказки пользователю о невыполненных условиях
   - Статусы фоновых процессов (пересборка, агенты)

## Цвета по исходам

- **Зелёный** (`"success"`) — операция полностью успешна
- **Жёлтый** (`"warning"`) — частичный успех (часть операций завершилась с ошибками)
- **Красный** (`"error"`) — полный провал (ни одна операция не успешна)
- **Синий** (`"info"`) — информация без результата операции

Для массовых операций уровень определяется автоматически через `notify.outcome_level(ok, total)`.

## Использование

### Одиночная операция

```python
from ui import notify

# Успех
notify.report("success", "Документ сохранён", {"id": 123})

# Ошибка
notify.report("error", "Не удалось сохранить", details=["Нет доступа к БД"])

# Короткое подтверждение без подробностей
notify.toast("Сохранено")
```

### Массовая операция

```python
from ui import notify

errors = []
ok_count = 0
for item in items:
    try:
        process(item)
        ok_count += 1
    except Exception as e:
        errors.append(f"{item.name}: {e}")

notify.report_batch("Обработано", ok_count, len(items), errors)
```

Уровень сообщения определяется автоматически:
- `ok == total` → зелёный
- `ok == 0` → красный
- `0 < ok < total` → жёлтый

### Идентификаторы в details

Если результат операции содержит ID (номер документа, источника и т.п.), передавайте его через `stats`, а не в заголовке:

```python
# Правильно
notify.report("success", "Документ опубликован", {"id": doc_id, "url": url})

# Неправильно (id в заголовке)
notify.report("success", f"Документ {doc_id} опубликован")
```

`stats` отображаются отдельной строкой в формате `ключ значение · ключ значение`.

## Проверка

Охранный тест `tests/test_no_bare_messages.py` автоматически проверяет отсутствие прямых вызовов `st.success/error/warning/info` в `ui/*.py` (кроме `notify.py`).

Если вызов допустим (пустое состояние, подсказка, статус процесса) — добавьте его в `ALLOWED` с комментарием, объясняющим причину исключения.

Запуск теста:

```bash
python3 -m pytest tests/test_no_bare_messages.py -v
```
